# Mickell Gunnesslal - Professional Profile Website

This folder is ready to publish with GitHub Pages.

## Publish on GitHub Pages
1. Create a GitHub repository. For the simplest personal site, name it `<your-username>.github.io`.
2. Upload `index.html`, `styles.css`, and the `assets` folder to the repository root.
3. In GitHub, open **Settings > Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will display the public URL when deployment completes.
5. Send that final URL back to ChatGPT so the business-card QR code can be replaced with the live URL.

## Privacy note
The page currently includes the phone number and email address from the supplied resume. Remove either item from `index.html` before publishing if you do not want it publicly indexed. The residential street address was intentionally omitted.
